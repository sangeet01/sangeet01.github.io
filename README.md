# Sangeet Sharma — Research Portfolio

Personal research portfolio of Sangeet Sharma — pharmacy undergrad in Nepal working at the intersection of chemistry, computation, and biology-inspired algorithms.


## Research & Projects

- **Numen**: Dense retrieval model bypassing dimension limits with Character N-Gram Hashing. First dense model to beat BM25 on DeepMind's LIMIT benchmark (arXiv:2601.15205).
- **SCRIPT**: Structural Chemical Representation In Plain Text. Sovereign molecular notation governed by a formal Paninian grammar.
- **Keybox**: In silico drug-excipient compatibility screening via 11-channel field theory and O(1) negative space matrix multiplication.
- **Khukuri**: Counter-evolutionary antibiotic discovery treating pathogen mutations as a zero-sum minimax game via the Darwin-Gödel loop.
- **Gradient Hashing**: Biology-inspired load balancing algorithm modeled after fungal nutrient transport and slime mould potential fields.
- **Matryoshka Protocol**: Steganographic messaging protocol achieving Shannon's three pillars simultaneously with Fractal Group Ratchet encryption.
